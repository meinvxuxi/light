## 2. 日常更新（先备份 → 拉代码 → 重启）
```bash
# 服务器上执行。若当前登录用户不是 root（例如显示 admin@...），先切换 root：
sudo -i
# （切换后再确认项目目录）
cd /root/light

# 旧写法：手动三步
tar czf /root/backup/before-update-$(date +%F).tgz data/
git pull
pm2 restart light
```

推荐用仓库内置的一键更新脚本（备份→拉代码→装依赖→重启，安全无副作用）：
```bash
sudo bash /root/light/deploy/update.sh
```

> 说明：登录用户可能不是 root（如 `admin`）。非 root 无法访问 `/root/`，
> 请先 `sudo -i` 切换 root；若项目其实不在 `/root/light`，先用
> `pm2 describe light`（看 script path）或 `find / -maxdepth 3 -name server.js 2>/dev/null` 找到真实目录再 cd。


## 3. 数据三层保障
1. **运行时自动落盘**：`data/` 目录自动保存 成就 / 时光墙 / 默契空间 / 留言板 / 用户档案（含昵称、主题、上次离线时间）。游客默认内存态不落盘。
2. **服务器每日备份**（已配置 crontab，每天 03:15）：
   ```bash
   15 3 * * * cd /root/light && tar czf /root/backup/light-data-$(date +\%F).tgz data/ && find /root/backup -name "light-data-*.tgz" -mtime +7 -delete
   ```
   保留最近 7 份，旧备份自动清理。
3. **阿里云云盘快照**：控制台 → ECS → 磁盘 → 自动快照策略（建议每周），系统盘损坏时可整机恢复。

## 4. 手动备份/恢复
```bash
# 备份
mkdir -p /root/backup
cd /root/light && tar czf /root/backup/manual-$(date +%F_%H%M).tgz data/

# 恢复（示例：恢复到某天的 data）
cd /root/light && mv data data.broken && tar xzf /root/backup/light-data-2026-09-07.tgz && pm2 restart light
```
