## 2. 🏅 荣誉墙（成就展示）
- 展示规则：
  - 没有任何正式玩家触发过的成就 → 整组不显示
  - 触发过的成就下列出获得者，样式：成就名 + 玩家 + 触发次数 + 首次触发时间
  - 排列：成就按品质高级→低级；同成就下玩家按"首次触发时间早的在前"
  - 每条默认显示"首次触发时间 + 累计触发次数"，右侧小三角 ▸ 可展开查看每次触发的具体时间（历史明细）
- 仅统计正式玩家；游客与测试者的成就不计入、不可见

## 3. 📜 时光墙（时间线）
- 记录正式玩家的比赛记录 与 成就达成时间线
- 时间线条目格式：
  - `yyyy年MM月dd日 HH:mm  哪几位玩家游玩了【游戏名】`
  - 小三角展开可看具体分数与排名
  - `yyyy年MM月dd日 HH:mm  谁获得了什么成就`
- 仅记录正式玩家，游客与测试者的记录不计入

## 4. 👤 个人空间（个人主页）
- 展示：玩家昵称、个性签名、常用角色、游玩场次、胜率统计、常玩游戏
- 仅正式玩家拥有；正式玩家之间可"双击对方的状态卡/主页卡片"进入其个人空间

## 5. 🏆 排行榜
- 内容：各游戏分数排行 + 锦标赛积分排行
- 正式玩家：可查看内部榜 与 含游客数据的排行榜
- 游客：仅可查看含游客数据的排行榜

## 6. 💬 留言板

# 🆕 新游戏与比赛系统规划（2026-09-06 用户新增）

## 一、花菜接龙（四人绘图接龙）
- 流程：每人先写一个词 → 第二个人猜 → 第三个画 → 第四个猜（猜时能看到字数）→ 公布时判断答案是否合理
- 判定：三人以上打勾（≥3）即判定"合理"
  - 合理 → 每人投一名"非自己"的 MVP，每票 +1
  - 不合理 → 每人投一名"非自己"的罪魁祸首，每票 -1
- 四组绘画同时进行；有提示"谁已确认"；全部提交确认后再进入下一棒

## 二、扫雷（个人战 / 2v2 组队）
- 棋盘 8×8，共 26 个雷
- 操作：点击=点开，长按=标记；每轮每人只能进行 1 个操作
- 计分：
  - 踩雷 或 标记到空格：-5
  - 标记到雷 或 翻开成功（空位）：加分，按该格同时被选的人数：1 人 +6、2 人 +3、3 人 +2、4 人 +1
  - 选错的人不影响其他人的加分
- 同步规则：选之前看不到谁选了哪里；选之后能看到目前的"选择情况"
- 界面显示：剩余雷数量
- 房间设置：可选 个人赛 / 组队赛(2v2)；选个人赛后再选房间人数
- 战绩：记录总场次；每种模式、每种人数的胜率分别统计

## 三、比赛模式 / 锦标赛系统
- 像"豹豹碰碰大作战"这类对抗游戏支持两种模式：
  - 休闲模式
  - 比赛模式（仅正式玩家可参与）
- 比赛模式内可选：BO1 / BO3 / BO5，包含 BP（禁选）系统
- 锦标赛：专门放置"锦标赛比赛积分"与"各小游戏比赛模式战况"的地方
- 可建立比赛：选择比赛项目、比赛名称；比赛结果永久记录
