
标准双人翻转棋（黑白棋 / 奥赛罗）开发规格文档
一、游戏概述
标准双人翻转棋，又称黑白棋、奥赛罗。两名玩家在 8×8 棋盘上轮流落子，通过夹击翻转对方棋子。游戏结束时棋子多者获胜。

二、棋盘与坐标系统
棋盘：8×8 方格，共 64 格。

坐标记法：列从左到右为 a~h，行从上到下为 1~8，格式为 字母+数字（如 a1、d5、h8）。

棋子颜色：黑、白两色。

棋子状态：每格可为空、黑棋、白棋。

三、初始布局
坐标	颜色
d4	白
e5	白
e4	黑
d5	黑
黑棋先手。

其余 60 格为空。

四、回合流程
当前玩家为黑或白。

计算当前玩家所有合法落子位置（get_legal_moves）。

如果存在合法落子：

玩家必须选择一个合法位置落子。

落子后，按规则翻转所有被夹住的对方棋子。

切换回合给对手。

如果不存在合法落子：

当前玩家必须弃权（Pass）。

不落子，直接切换回合给对手。

如果对手也无合法落子，游戏结束。

注意：只要存在合法落子，玩家不能主动弃权。

五、合法落子与翻转规则
5.1 合法落子条件
一个空位 (r, c) 对当前玩家 P 合法，当且仅当：

在该位置放下 P 后，在八个方向（上、下、左、右、左上、右上、左下、右下）中，至少有一个方向满足：

从 (r, c) 出发，沿该方向连续遇到至少一枚对方棋子；

这些连续对方棋子之后，紧接着一枚己方棋子 P；

中间不能有空格，也不能有己方棋子提前截断。

5.2 翻转规则
落子后，对于每一个满足上述条件的方向：

将该方向上所有被夹住的对方棋子翻转为当前玩家颜色。

如果多个方向同时满足，则所有方向上的对方棋子全部翻转。

翻转只影响被夹住的连续对方棋子。

5.3 角落规则
棋盘四个角落 a1、h1、a8、h8 的棋子永远不会被翻转。

六、弃权与游戏结束
6.1 弃权
如果当前玩家没有任何合法落子位置，则自动弃权，回合交给对手。

如果对手也无合法落子，则游戏结束。

6.2 结束条件
棋盘 64 格全部填满。

双方都没有合法落子位置（即连续两次弃权）。

6.3 胜负判定
游戏结束后，统计棋盘上黑棋与白棋的数量。

棋子数量多者获胜。如果双方棋子数量相同，则为平局。

七、界面与操作建议
显示 8×8 棋盘网格，坐标标注在棋盘边缘（列 a~h，行 1~8）。

棋子用圆形表示，黑色与白色区分玩家。

当前回合玩家高亮显示。

高亮当前玩家所有合法落子位置（黄点或半透明标记）。

玩家点击合法位置后落子，并播放翻转动画。

显示双方当前棋子数量。

当一方弃权时，显示“Pass”提示。

游戏结束弹出结算画面，显示获胜方或平局。

八、棋谱导出（走步记录）
游戏应支持导出走步记录，格式为坐标串（黑方第一步在前，白方第二步，交替排列）。

示例：

text
f5d6c3d3c4f4f6f3e6e7c6...
奇数位为黑方落子，偶数位为白方落子。

导出时自动拼接，无需标注颜色。

可提供“复制棋谱”按钮，方便分享或复盘。

九、核心算法伪代码
text
初始化 board[8][8] 全部为空
board[d4] = WHITE   // (3,3)
board[e5] = WHITE   // (4,4)
board[e4] = BLACK   // (3,4)
board[d5] = BLACK   // (4,3)

current = BLACK
pass_count = 0

while true:
    legal_moves = get_legal_moves(current, board)

    if legal_moves 为空:
        pass_count += 1
        if pass_count >= 2:
            break
        current = opponent(current)
        continue

    pass_count = 0
    等待玩家从 legal_moves 中选择一个位置 (r, c)
    在 board[r][c] 放置 current 颜色棋子

    for 每个方向 (dr, dc) in 八个方向:
        path = []
        rr = r + dr; cc = c + dc
        while 棋盘内(rr, cc) 且 board[rr][cc] == opponent(current):
            path.append((rr, cc))
            rr += dr; cc += dc
        if path 非空 且 棋盘内(rr, cc) 且 board[rr][cc] == current:
            for (pr, pc) in path:
                board[pr][pc] = current

    current = opponent(current)

统计 board 中 BLACK 与 WHITE 数量
宣布棋子多者获胜，或平局
十、关键函数说明
get_legal_moves(player, board)
返回当前玩家所有合法落子位置的列表。

text
moves = []
for 每个空格 (r, c):
    for 每个方向 (dr, dc):
        path = []
        rr = r + dr; cc = c + dc
        while 棋盘内(rr, cc) 且 board[rr][cc] == opponent(player):
            path.append((rr, cc))
            rr += dr; cc += dc
        if path 非空 且 棋盘内(rr, cc) 且 board[rr][cc] == player:
            moves.append((r, c))
            break
return moves
apply_move(player, board, r, c)
在 (r, c) 落子并翻转所有被夹住的对方棋子。

十一、边界与注意事项
不能落在非空格。

不能落在无法翻转任何对方棋子的位置。

翻转时只翻转被夹住的连续对方棋子。

角落棋子永不被翻转（a1、h1、a8、h8）。

## 十三、数据与生态（2026-09-09 落地）

- **排行榜**：新增「翻转棋」榜；最佳 = 单局最高终局棋子数（每人一条），分数 = 终局棋子数前 20 流水。
- **个人空间**：翻转棋战绩含 场次 / 胜场 / 平局场数 / 胜率 / 累计终局棋子数 / 单局最高终局棋子数。
- **时光墙**：真实整局记录个人终局棋子数、名次与平局标记。
- **结算体验**：终局客户端 3 秒后自动收起棋盘，结果页可点「展开棋盘 / 收起棋盘」反复查看；服务器 8 秒后结算房间（复位准备、可开新局），数据先行入库。
- **走步记录**：结算页展示并支持「复制走步记录」（奇数位黑、偶数位白坐标串）。
- **表情系统**：页面接入全局表情包挂件（ovo 大面板 / =w= 托盘 / TAT 静音，与其它游戏一致）。
