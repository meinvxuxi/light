# 💣 炸飞机（四人版）开发文档

## 一、游戏概述
- 类型：回合制推理轰炸
- 人数：2-4人
- 棋盘：15×15
- 飞机：每名玩家5架（三种机型各至少1架，剩余2架随机）
- 胜利条件：存活到最后（五架飞机未被全部击沉）

飞机摆放时可朝上、下、左、右四个方向旋转。旋转时以机头为原点，所有坐标进行对应变换。

## 三、摆放规则
1. 5架飞机必须完全在15×15棋盘内
2. 飞机之间不能重叠
3. 三种机型各至少出现1架，剩余2架从三种机型中随机抽取
4. 摆放完成后，服务器验证合法性

## 四、回合流程
1. 玩家轮流轰炸一个坐标（格式：横5竖8）
2. 被轰炸的玩家反馈该坐标状态：空 / 伤 / 沉
3. 三人四人模式特殊规则：A轰炸B时，C和D的同格坐标也会被炸开
4. 击中机头则整架飞机直接击沉
5. 五架飞机全部被击沉的玩家被淘汰
6. 最后存活的玩家获胜

## 五、多人轰炸传播
- A选择轰炸B的坐标(x,y)
- 服务器检查A对B的轰炸结果
- 同时检查坐标(x,y)在C和D的棋盘上是否有飞机
- C和D的同格飞机同样受到伤害
- 传播伤害不会影响C和D对被轰炸者的反馈

## 六、赛后统计（不影响输赢）
- 首中机身步数：首次击中敌方飞机时的回合数
- 首次击毁步数：首次击落敌方飞机时的回合数
- 共击打机身格数：累计命中机身的格子总数
- 共击毁飞机数：累计击落的飞机总数
