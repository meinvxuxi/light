# SkillGomoku.md

## 一、项目概述

制作一款支持2-4人的技能五子棋游戏。在15×15棋盘上，玩家选择不同角色，利用各自独特技能，争夺最先达成3次五连的胜利。游戏融合传统五子棋的落子逻辑与角色技能博弈，节奏快、变化多、娱乐性强。

## 二、基本信息

- **类型**：回合制棋类 / 技能博弈
- **人数**：2-4人
- **棋盘**：15×15
- **时长**：15-25分钟一局

## 三、游戏目标

在15×15棋盘上轮流落子，**最先达成3次五连（横竖斜均可）的玩家获胜**。

### 3.1 胜利后处理

- 默认模式：任意玩家达成胜利条件后，游戏**立即结束**，该玩家获胜。
- 可选模式：设置中可开启“继续决出排名”，第一名产生后剩余玩家继续对局，依次决出第二、第三、第四名。默认关闭。

## 四、回合流转

- 玩家轮流落子，每轮各走一步
- 初始顺序随机排列（除掌权者外）
- 掌权者若在场，必定排在第1顺位
- 2人局时，双方轮流落子，无掌权者先手规则

## 五、角色技能

共8个角色，每局玩家各选一个，不可重复。

| 角色 | 技能 |
|------|------|
| **掌权者** | **必定先手**（每局固定第1顺位）。若连成共用一子的两个五连，**直接获胜**。同时正常参与竞速。 |
| **幸运儿** | 每次五连后，可**额外落一子**。此额外落子若再次形成五连，不重复触发。 |
| **封印师** | 每轮可**锁定一个位置**（持续一轮，双方均不可落子）。下轮可换锁新位置，旧锁自动解除。不能连续两轮封锁同一位置。 |
| **清洁工** | 五连**计分后**，清除这五个棋子，并**额外移除两颗敌子**（不能是同一人的）。 |
| **侦探** | 高亮显示自己当前**差一子就五连的所有空位**（仅自己可见）。 |
| **灵魂棋手** | 在达成**第一次五连前**，可在已有他人棋子的位置落子（棋子共存）。第一次五连后，此能力永久失效，已寄生的棋子保留。 |
| **摸鱼高手** | 累计达成**5次四连**直接获胜。同时正常参与竞速。 |
| **截码战专家** | 每轮秘密选择**两个预测点**。猜中一人落子+1分，猜中两人+3分。满18分减少一次五连需求，满36分减少两次，满54分直接获胜。预测点每轮刷新，仅自己可见，其他玩家只能看到累计积分。 |

### 5.1 技能实现细节

**掌权者**：
- 双重五连判定：两个五连共用至少一枚棋子，且两个五连方向不同或同方向但位置不同。
- 达成后立即获胜，不等待其他玩家。

**幸运儿**：
- 五连计分后，立即获得一次额外落子机会。
- 额外落子若再次形成五连，该五连正常计分，但**不触发额外落子**（防止无限连锁）。
- 额外落子结束后，回合正常结束。

**封印师**：
- 每轮可选择锁定一个棋盘空位，该位置在**本轮内**双方均不可落子。
- 下轮开始时，旧锁自动解除，可重新选择新位置。
- 不能连续两轮封锁同一位置（需记录上轮锁定位置）。
- 锁定位置不能是已有棋子的位置。

**清洁工**：
- 五连计分后，清除这五个棋子。
- 额外移除两颗敌子，这两颗敌子不能属于同一玩家（即不能只移除一个人的两颗棋子）。
- 若场上敌子不足两颗（如2人局中只有一名对手），则只移除能移除的。

**侦探**：
- 仅自己可见的高亮提示。
- 高亮显示所有“差一子就五连”的空位（即已有四连，任意一端空位）。
- 高亮不消耗任何资源，持续显示。

**灵魂棋手**：
- 第一次五连前，可在已有他人棋子的位置落子，形成“共存”状态（该位置同时有两枚棋子）。
- 共存棋子不占据额外格子，同一位置可存在两枚不同颜色的棋子。
- 五连判定时，只看自己的棋子，共存不影响判定。
- 第一次五连后，能力永久失效，已寄生的棋子保留在棋盘上。

**摸鱼高手**：
- 四连定义为：任意方向上有连续四枚己方棋子，且两端至少一端为空（可延伸为五连）。
- 累计达成5次四连直接获胜。
- 四连可重复计算（同一棋子参与多个四连）。
- 同时正常参与竞速（3次五连也可获胜）。

**截码战专家**：
- 每轮秘密选择两个预测点（棋盘空位）。
- 每轮结束时，检查所有玩家本轮的落子：
  - 猜中一人落子（预测点与某玩家落子位置相同）+1分
  - 猜中两人落子（两个预测点分别命中两个不同玩家的落子）+3分
  - 若两个预测点命中同一玩家的落子，按+1分计算（不叠加）
- 预测点每轮刷新，仅自己可见。
- 其他玩家只能看到累计积分，看不到预测点。
- 满18分：五连需求从3次减为2次。
- 满36分：五连需求从3次减为1次。
- 满54分：直接获胜。
- 积分在达到阈值后立即生效。

## 六、获胜条件

- **标准竞速**：最先达成3次五连者获胜。
- **特殊获胜**：
  - 掌权者的双重五连（共用一子的两个五连）
  - 摸鱼高手的5次四连
  - 截码战专家的54分直接获胜
- 以上均为独立胜利条件，达成即立即获胜。

## 八、界面与操作

- 15×15棋盘网格，坐标标注可选。
- 棋子用圆形表示，不同玩家不同颜色。
- 当前回合玩家高亮显示。
- 合法落子位置可点击。
- 封印师锁定位置以特殊标记显示（如锁图标）。
- 灵魂棋手共存位置显示两枚棋子叠加（半透明）。
- 侦探高亮提示仅己方可见（如闪烁边框）。
- 截码战专家预测点仅己方可见（如小标记）。
- 显示各玩家五连进度（如3/3）、四连进度、积分等。
- 游戏结束弹出结算画面，显示获胜者及达成方式。

### 8.1 个人主页数据统计

个人主页显示以下统计项：

| 统计项 | 说明 |
|---|---|
| 角色使用次数 | 每个角色被选择的次数 |
| Pick率 | 该角色使用次数 / 总对局数 |
| 胜率 | 该角色获胜次数 / 该角色使用次数 |
| 总对局数 | 玩家参与的总局数 |

## 九、开发任务

请根据以上规则，实现以下功能：

1. **核心棋盘逻辑**：15×15棋盘，落子、五连判定（横竖斜）、四连判定。
2. **回合系统**：2-4人轮流落子，掌权者先手，其他随机。
3. **角色选择**：8个角色，每局各选一个，不可重复。
4. **技能实现**：按第五章5.1节的细节实现每个角色的技能。
5. **胜负判定**：标准3次五连获胜 + 三个特殊获胜条件。
6. **胜利后处理**：默认直接结束，可选“继续决出排名”模式。
7. **成就系统**：按第七章实现成就触发与解锁提示，以及头衔奖励。
8. **个人主页**：按第八章8.1节实现角色数据统计。
9. **界面交互**：按第八章实现棋盘显示、技能UI、提示系统。
10. **多人模式**：支持2-4人本地轮流操作（或AI对战，视开发范围而定）。

**优先级**：
- P0：核心棋盘逻辑、回合系统、胜负判定
- P1：角色技能、成就系统、头衔奖励
- P2：个人主页统计、界面美化、动画效果、音效
