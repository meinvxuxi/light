# Quoridor-Standard-Multi-Player-Development-Spec.md

## 一、游戏概述

路墙棋（Quoridor），中文又译“墙棋”“步步为营”，是由Mirko Marchesi于1997年设计、Gigamic Games发行的抽象策略棋类游戏，支持2至4人对战。游戏在9×9棋盘上进行，每方拥有一枚棋子和若干片长度为两格的墙壁。玩家每回合必须在“移动棋子”和“放置墙壁”之间二选一，目标是最先将自己的棋子移动到棋盘对边。

该游戏于1997年被门萨国际评选为推荐游戏，1998年获Games Magazine年度游戏大奖。

## 二、棋盘与坐标系统

- **棋盘**：9×9方格，共81格。格子之间有沟槽，用于放置墙壁。
- **坐标记法**：列从左到右为 **a~i**，行从上到下为 **1~9**，格式为**字母+数字**（如 `a1`、`e5`、`i9`）。
  - 左上角：`a1`，右下角：`i9`。
  - 中心格：`e5`。
- **沟槽（墙壁位置）**：沟槽位于格子之间。横墙（`H`）位于两行之间，占据左右相邻两格下方的水平沟槽；竖墙（`V`）位于两列之间，占据上下相邻两格右侧的垂直沟槽。墙壁以“起始坐标 + 方向”表示：
  - 横墙 `H`：以左上角格子的坐标表示，占据该格右侧和下侧之间的沟槽，长度覆盖两格。例：`(e5, H)` 表示位于 `e5` 与 `f5` 下方、`e6` 与 `f6` 上方的水平墙壁。
  - 竖墙 `V`：以左上角格子的坐标表示，占据该格右侧的垂直沟槽，长度覆盖两格。例：`(e5, V)` 表示位于 `e5` 与 `f5` 之间、`e6` 与 `f6` 之间的垂直墙壁。
- **沟槽数量**：横墙沟槽有 **8行 × 9列 = 72** 个可放置位置，竖墙沟槽有 **9行 × 8列 = 72** 个可放置位置，合计 **144** 个候选墙壁位置。

## 四、回合行动

每回合，当前玩家**必须**执行以下**两种行动之一**，不能跳过回合：

### 4.1 行动A：移动棋子

将棋子向**上下左右**四个方向之一移动一格。移动必须遵守以下规则：

**基础移动**：
- 目标格必须在棋盘内。
- 目标格不能有墙壁阻隔。
- 目标格不能有其他玩家的棋子。

**跳跃规则（核心）**：

如果目标格有**一名其他玩家的棋子**，不能直接移动到该格，但可以**跳过**该棋子：

1. **直跳**：被跳过棋子的**后方格**在棋盘内、无墙壁阻隔、无其他棋子，则直接跳到后方格。
2. **斜跳**：直跳不可用时（后方出界/有墙/有棋子），可以跳到被跳过棋子的**左右两侧**格子。斜跳**只在直跳不可用时才解锁**。
3. 一次移动**最多跳过一名棋子**。

### 4.2 行动B：放置墙壁

将一片己方墙壁放入棋盘沟槽中：

**基本放置规则**：
- 墙壁必须完全在棋盘内。
- 墙壁必须与网格对齐，横放或竖放。
- 墙壁长度为两格。
- 放置位置必须有空的沟槽，不能与已有墙壁重叠或交叉。

**合法性核心规则**：
> **放置墙壁后，必须保证所有未完成玩家仍然存在至少一条通往各自目标边的路径。**

**墙壁数量限制**：
- 墙壁一旦放置，直到游戏结束都不能移动或收回。
- 墙壁用完时，该玩家只能选择移动棋子。

## 五、游戏结束与胜负判定

### 5.1 单人完成条件

当任意一名玩家的棋子**到达其目标边**时，该玩家**完成比赛**，记录其名次。

### 5.2 多人排名规则

- **第一名到达终点的玩家**获得胜利，名次为第1名。
- 第一名产生后，**该玩家的棋子从棋盘上移除，不再参与后续回合**。
- **剩余玩家继续正常对局**，目标不变，回合顺序跳过已完成玩家。
- 当第二名到达终点后，同样冻结，名次为第2名。剩余玩家继续。
- 当只剩**一名未到达的玩家**时，该玩家**自动成为最后一名**，游戏结束。
- 当只剩**两名未到达的玩家**时，其中一人到达终点，另一人自动成为下一名次，游戏结束。

### 5.3 边界情况

- 多人同时到达：回合是顺序执行的，同一回合只有一人行动，按到达先后判定名次。
- 已完成玩家的已放置墙壁**仍然留在棋盘上**，继续阻挡所有棋子。
- 剩余玩家中不会出现死局，因为标准规则不允许“堵死”。

## 六、成就系统

游戏内置成就系统，达成条件时弹出解锁提示。

| 稀有度 | 成就名 | 条件 |
|---|---|---|
| 普通 | 一堵定乾坤 | 放置一片墙壁后，使任意对手的最短路径长度增加10格或以上 |
| 普通 | 天选建筑师 | 两人对局中，到达终点时对手最短路径长度 ≥ 15 |
| 稀有 | 镜流与近路 | 在10个回合内到达终点 |
| 稀有 | 步步为营 | 在只剩两人且两人最短路径都为1时到达终点；或剩余三人最短路径都为1时抵达终点且获得亚军 |
| 史诗 | 真·步步为营 | 在三或四人局中，所有未完成玩家最短路径都为1时抵达终点，且获得冠军 |
| 传说 | S1导演 | 不使用任何属于自己的墙壁获得胜利 |

**成就触发说明**：
- **一堵定乾坤 / 天选建筑师**：需要在放置墙壁前后分别计算对手的最短路径长度，取差值。
- **镜流与近路**：从游戏开始到该玩家到达终点，总回合数 ≤ 10。
- **步步为营**：
  - 情况一：对局中只剩两名未完成玩家，且两人最短路径均为1。此时其中一人到达终点，该玩家解锁成就。
  - 情况二：对局中剩余三名未完成玩家，且三人最短路径均为1。此时其中一人到达终点并成为亚军（即并非第一个到达），该玩家解锁成就。
- **真·步步为营**：三或四人局中，所有未完成玩家的最短路径均为1。此时该玩家到达终点并获得冠军（第1名），解锁成就。
- **S1导演**：终局时该玩家已放置的墙壁数量为0。

### 9.2 回合循环

```text
while not gameOver:
    跳过 finished 中的玩家，找到下一个未完成的玩家 currentPlayer
    等待 currentPlayer 选择行动

    if 行动类型 == "移动":
        目标坐标 = 玩家选择的目标格
        合法移动列表 = getLegalMoves(currentPlayer, board, pawns, walls)
        if 目标坐标 not in 合法移动列表:
            提示非法，重新选择
            continue
        执行移动：pawns[currentPlayer] = 目标坐标
        if 目标坐标 在 goals[currentPlayer] 上:
            finished.append(currentPlayer)
            从棋盘移除 pawns[currentPlayer]
            if len(finished) >= 玩家数 - 1:
                gameOver = true
                break

    elif 行动类型 == "放置墙壁":
        if wallCount[currentPlayer] <= 0:
            提示无墙壁可用，重新选择
            continue
        墙壁位置 = 玩家选择的 (r, c, orient)
        if not isWallLegal(r, c, orient, board, pawns, walls):
            提示非法，重新选择
            continue
        放置墙壁：walls.append((r, c, orient))
        wallCount[currentPlayer] -= 1

    切换到下一个未完成的玩家
```

### 9.3 移动合法性检查

```text
function getLegalMoves(player, board, pawns, walls):
    moves = []
    r, c = pawns[player]
    for each direction (dr, dc) in [(0,1), (0,-1), (1,0), (-1,0)]:
        nr, nc = r + dr, c + dc
        if not inBoard(nr, nc):
            continue
        if hasWallBetween((r,c), (nr,nc), walls):
            continue
        if (nr, nc) not occupied by any active pawn:
            moves.append((nr, nc))
        else:
            opponentPos = (nr, nc)
            behind = (nr + dr, nc + dc)
            if inBoard(behind) and not hasWallBetween((nr,nc), behind, walls) and behind not occupied:
                moves.append(behind)
            else:
                leftDir = (dr == 0) ? (1, 0) : (0, 1)
                rightDir = (dr == 0) ? (-1, 0) : (0, -1)
                for each sideDir in [leftDir, rightDir]:
                    side = (nr + sideDir[0], nc + sideDir[1])
                    if inBoard(side) and not hasWallBetween((nr,nc), side, walls) and side not occupied:
                        moves.append(side)
    return moves
```

### 9.4 墙壁合法性检查（BFS）

```text
function isWallLegal(r, c, orient, board, pawns, walls):
    if orient == 'H':
        if r < 0 or r >= 8 or c < 0 or c >= 8:
            return false
        if (r, c, 'H') in walls or (r, c+1, 'H') in walls:
            return false
        if (r, c, 'V') in walls or (r, c+1, 'V') in walls:
            return false
    elif orient == 'V':
        if r < 0 or r >= 8 or c < 0 or c >= 8:
            return false
        if (r, c, 'V') in walls or (r+1, c, 'V') in walls:
            return false
        if (r, c, 'H') in walls or (r+1, c, 'H') in walls:
            return false

    tempWalls = walls + [(r, c, orient)]
    for each player i not in finished:
        if not hasPathToGoal(pawns[i], goals[i], tempWalls):
            return false
    return true

function hasPathToGoal(start, goalEdge, walls):
    queue = [start]
    visited = set()
    while queue not empty:
        pos = queue.pop(0)
        if pos in visited: continue
        visited.add(pos)
        if isOnGoalEdge(pos, goalEdge):
            return true
        for each neighbor (nr, nc) of pos:
            if inBoard(nr, nc) and not hasWallBetween(pos, (nr,nc), walls):
                queue.append((nr, nc))
    return false
```

### 9.5 墙壁对图的影响

```text
function hasWallBetween(cell1, cell2, walls):
    r1, c1 = cell1
    r2, c2 = cell2
    if r1 == r2:
        c_min, c_max = min(c1, c2), max(c1, c2)
        for each wall (wr, wc, orient) in walls:
            if orient == 'V':
                if (wr == r1 or wr == r1 - 1) and wc == c_min:
                    return true
    elif c1 == c2:
        r_min, r_max = min(r1, r2), max(r1, r2)
        for each wall (wr, wc, orient) in walls:
            if orient == 'H':
                if (wc == c1 or wc == c1 - 1) and wr == r_min:
                    return true
    return false
```

## 十、边界与注意事项

- 墙壁**不能伸出棋盘边缘**。
- 墙壁**不能与已有墙壁重叠或交叉**。
- 墙壁放置后**不能移动或收回**。
- 棋子**不能穿过墙壁**。
- 跳跃时，**直跳优先于斜跳**。直跳可用时，**只能**直跳。
- 一次移动**最多跳过一名棋子**。
- 墙壁放置的合法性检查是**全局图搜索（BFS）** ，不能使用局部查表。
- 已完成玩家的已放置墙壁**仍然留在棋盘上**，继续阻挡所有棋子。
- 剩余玩家中不会出现死局，因为标准规则不允许“堵死”。
- **走步记录**存放在“时光墙”中，通过小展开按钮访问，不占据结算页主视觉。
- **终点高亮**使用红/蓝/绿/黄对应各玩家目标边。
- **玩家视角**：己方棋子始终位于屏幕下方，棋盘根据当前玩家旋转。
- **棋子**：棋子用玩家专属表情包代替，即扫雷A的表情包。
- **成就系统**与**头衔系统**相互独立，头衔根据达成任意一个当前档位成就解锁。
