# 🏆 锦标赛系统设计文档

## 一、系统定位

锦标赛是游戏室的竞技核心。分为标准锦标赛和自定义比赛两种模式。所有比赛战绩独立记录，与普通对局战绩分离。

---

## 二、标准锦标赛

### 2.1 基本设定
- 人数：2人对抗（两人锦标赛为试训，和四人锦标赛战绩分开记录，四人锦标赛为正式比赛，有赛季，排名等。每次冠军有专属称号和专属纪念品（纪念品可展示在个人主页，系统还未完善））
- 赛制：BO3 / BO5（可调）
- 游戏池：随机从游戏室已有小游戏中抽3个
- 选图方式：每轮开赛前使用以下两种方式之一确定对局游戏

### 2.2 选图机制

**方式一：Ban图制**
1. 系统随机从小游戏库中抽取3个游戏
2. 两名选手各禁用一个游戏
3. 若双方禁用不同 → 剩下那个没被禁用的游戏作为本轮游戏
4. 若双方禁用相同 → 系统随机从剩余两个没被禁用的游戏中选一个

**方式二：选图制**
1. 系统随机从小游戏库中抽取3个游戏
2. 两名选手各选择一个想玩的游戏
3. 从他们选择的游戏里随机抽取一个作为本轮游戏
4. 若两人选择相同 → 直接使用该游戏

方案三（优选）：
由先手玩家禁选一张图，后手玩家在剩下两张里选一张。每个小游戏结束先后手互换。若双方都到达赛点，开启巅峰对决（要炫酷特效），巅峰对决每个人在所有小游戏中选两个，再各ban一个对方的，然后系统随机抽取一张图。若双方选的小游戏完全相同则直接随机不用ban

### 2.3 战绩记录
锦标赛战绩保存在独立的锦标赛战绩栏中，与普通对局完全分离：
-比赛名，排名，展开查看详细每局小游戏选择与每局得分
- 玩家名
- 对手名
- 赛制（BO3/BO5）
- 各局使用游戏及胜负
- 总比分
- 最终胜负
- 比赛时间
- 对局时长

---

## 三、四人锦标赛

### 3.1 基本设定
- 人数：4人
- 赛制：先两两对打，胜者与胜者打决赛，败者与败者打季军赛
- 每轮对抗使用标准BO3/BO5规则

### 3.2 流程
```
第一轮：A vs B（胜者进决赛）  C vs D（胜者进决赛）
第二轮：胜者A/B vs 胜者C/D（决出冠军）  败者A/B vs 败者C/D（决出季军）
```

### 3.3 观战
- 未参与当前对局的玩家可选择观战
- 观战视角：上帝视角 / 单人视角
- 观战时可发送表情互动

### 3.4 战绩记录
四人锦标赛战绩独立归类，标注：
- 参赛四人名单
- 第一轮对阵及比分
- 决赛/季军赛对阵及比分
- 最终排名（冠军/亚军/季军/殿军）

---

## 四、自定义比赛

### 4.1 创建比赛
创建者（房主）可设置以下参数：

| 参数 | 说明 |
|------|------|
| 人数 | 2人 / 4人 |
| 规则 | BO3 / BO5 / 积分赛（自定义积分目标） |
| 游戏 | 单选或多选（多选则每轮随机或按顺序） |
| 备注 | 自定义文字，显示在比赛房间内 |

### 4.2 比赛版本适配
部分游戏会推出"比赛版本"，与普通版不同：
- **豹豹碰碰比赛版**：加入BP环节（角色禁用/选择）
- **炸飞机比赛版**：待定
- **浮标商战比赛版**：角色不可重复选择
还有更多，待定

### 4.3 积分赛规则（之后会做专门适配）
- 自定义积分目标（如先到100分）
- 每局按游戏结果获得积分
- 先达到目标积分者获胜

### 4.4 历史比赛记录
自定义比赛战绩独立记录，包含：
比赛名，备注，排名，参与者，具体情况。
- 创建者
- 参赛玩家
- 规则参数
- 备注内容
- 每局游戏及比分
- 最终胜负/排名
- 比赛时间

## 五、历史比赛一栏

### 5.1 页面结构
```
📜 历史比赛
├── 切换标签：[锦标赛] [训练赛]（训练赛是自定义比赛）
│   ├── 标准锦标赛
│   │   ├── 切换：[联赛] [单练]（联赛是四人赛，单练是两人赛）
│   │   └── 战绩列表（按时间倒序）
│   └── 自定义比赛
│       ├── 切换：[联赛] [单练]
│       └── 战绩列表（按时间倒序）
└── 战绩详情弹窗
```

### 5.2 战绩列表条目
- 参赛玩家名单
- 赛制标签（BO3/BO5/积分赛）
- 总比分
- 比赛日期
- 点击展开查看各局详情

### 5.3 战绩详情
- 各局使用游戏
- 各局胜负
- 最终结果
- 备注内容（自定义比赛）
- 比赛时长
