# 🎨 专属 UI 素材库

每位玩家一个文件夹，把喜欢的动漫角色图片放进去即可。

## 目录对应

| 文件夹 | 对应玩家 | 建议内容 |
|--------|---------|---------|
| `avatars/p1/` | 玩家1（密钥 aaaa） | 玩家1 喜欢的角色 |
| `avatars/p2/` | 玩家2（密钥 bbbb） | 玩家2 喜欢的角色 |
| `avatars/p3/` | 玩家3（密钥 cccc） | 玩家3 喜欢的角色 |
| `avatars/p4/` | 玩家4（密钥 dddd） | 玩家4 喜欢的角色 |

## 怎么放图片

1. 打开图片文件夹：把项目里的 `public\assets\avatars\p1` 路径粘贴到文件资源管理器地址栏回车；
2. 把你选好的角色图片 **拖进对应文件夹**；
3. 把最想当头像的那张**重命名为 `avatar.png`**（或 avatar.jpg），我默认读取它当头像；
4. 其他想留作背景/备选的图保持原名放着即可。

> 建议用 **PNG（透明背景）**，效果最好；尺寸 256×256 以上即可。

## 命名规则
- 文件名用英文/拼音、无空格：如 `avatar.png`、`star.png`；
- 每人文件夹放一张 `avatar.png` 当主头像。

## 放好后
告诉我一声（例如"四张头像都放好了"），我就会把它们接入：
- 大厅四张状态卡头像
- 房间座位头像
- 游戏玩家条头像
- 后续：每位玩家的专属主题色与背景元素
